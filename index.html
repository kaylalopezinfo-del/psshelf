What it does

Your visual second brain

Every pin becomes a real record: searchable, budgeted, and filed on the board it belongs to.

Save with context

One click on any pin captures the image, title and source — then asks for what Pinterest never does: a note, tags, a price, and which board it belongs to.

Search that actually works

Search your own notes, tags and titles at once, then filter down by board or box. Your words, not Pinterest's algorithm.

Boards, boxes & collages

Group pins into boards, file boards into boxes, and pull any set of pins into a collage you can export as one image.

How it works

Three steps between inspiration and done

1

Save from Pinterest

Browse Pinterest like you always do. On any pin, click "Save to P.S. Shelf" and add a note while the idea is fresh.

2

Organize into boards

File it on a board, add a price, group boards into boxes. P.S. Shelf keeps the running totals so you always know where a project stands.

3

Find it when it matters

Standing in the tile aisle? Search your own words — not Pinterest's algorithm — and pull up exactly the pin you need.
