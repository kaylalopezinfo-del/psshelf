What it does

Pinterest saves pins.
P.S. Shelf saves the thought.

Every feature is built around one thing: the context you had when you found something should still be there when you need it.

📝
Notes on every pin
Write what you actually thought — measurements, comparisons, reasons. Notes search just like pin titles.
🏷
Tags that filter
Tag across boards — "shortlisted", "ordered", "under $500" — then filter your shelf instantly.
💰
Budget tracker
Add prices to pins. Set board budgets. Track running totals so you always know where a project stands.
📦
Boxes for projects
Group boards into project boxes — kitchen remodel, wedding, travel — all in one place.
🔄
Multi-board pins
Save the same pin to multiple boards at once. A nail inspo in "Nail Inspo" and "July Inspo" simultaneously.
💾
Export everything
CSV, HTML, PDF, or ZIP — your data exports anytime. No lock-in, it's yours.
📊
Board health audit
See which boards are active, dormant, or inactive. Clean up what's not working.
☁️
Cloud sync
Sign in once and your entire shelf syncs across every device automatically.
🎨
Collage builder
Pull any pins into a mood board. Grid, masonry, or polaroid layouts. Export as one image.
How it works

Hover. Save. Find it later.

P.S. Shelf lives inside Pinterest as a floating sidebar. You never leave the page.

1
Hover any pin
A toolbar appears on the pin. Tap P.S. for an instant save, or tap a board circle to open the save form pre-filled.
2
Add your context
Write a note, add tags, set a price. Or save instantly and organize later — the pin is already in your Shelf.
3
Find it when it matters
Open the sidebar, search your own words, filter by board or tag. Everything — every note, price, and tag — is there instantly.
